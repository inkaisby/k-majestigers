# K-Majestigers

> Elite Karate Academy & Championship Arena

Platform interaktif untuk K-Majestigers Karate Academy & Championship Arena.

## Fitur Utama
- **Profil Akademi & Filosofi**: Informasi kurikulum dan tingkatan sabuk.
- **Tournament & Championship Arena**: Simulasi/jadwal kejuaraan dan arena pertandingan.
- **Pendaftaran & Keanggotaan**: Formulir pendaftaran dojo & turnamen.

## Menjalankan Secara Lokal
Buka file `index.html` langsung di browser atau gunakan local server:
```bash
# Menggunakan Python
python -m http.server 8000

# Menggunakan Node.js
npx serve .
```
